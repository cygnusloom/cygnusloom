Measured usage

Provider-reported token counts from completed AI GM replies

Showing: {{ period.label }}. Dates are UTC. {% if period.error %}{{ period.error }} Showing all time instead.{% endif %}

Token figures use only calls where the provider reported exact usage. Calls without a report are counted separately and are never estimated into the token columns. Input is split into Cache hit input, the part of the prompt served from the provider's prompt cache, and Cache miss input, the rest. Output includes reasoning (thinking) tokens. Averages are per reported reply, across every model call that reply made; a reply can make several calls, for example while using tools, so Calls can be higher than Replies.
